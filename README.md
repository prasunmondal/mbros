# Mondal Brothers

Website and installable web app for Mondal Brothers, a fresh-chicken supplier to shops and hotels. It has two pages: a storefront (`index.html`) and a Retail Calculator for shopkeepers (`retail-calculator/`).

The site is plain HTML, CSS and JavaScript with no build step. To run it locally:

```bash
npx serve .
```

Project knowledge such as the business rules, architecture, and decision records lives in `.claude/context/`. Start with `CLAUDE.md`.
